# 전장의 기사

486 시절 격자 턴제 택티컬 RPG. 브라우저에서 바로 플레이.

## 실행

```bash
cd "game/전장의 기사"
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8765 를 연다. `index.html`을 더블클릭해도 된다.

## 폴더

```
전장의 기사/
  index.html      게임 시작
  css/            화면
  js/             전투·AI·맵
  assets/sprites/ 캐릭터 그림
  docs/DESIGN.md  규칙
  tools/          테스트·스프라이트 처리
```

## 조작

- 클릭: 아군 선택 → 파란 칸 이동 → 공격/치료/대기
- 방향키 / Enter / Esc
- Space: 대기
- 페이즈 종료: 남은 아군을 대기시키고 적 턴

## 직업

| 이름 | 직업 | 이동 | 특징 |
|---|---|---|---|
| 검호 | 전사 | 4 | 보병, 사거리 1 |
| 성하 | 기사 | 7 | 기병. 숲에서 느림 |
| 류진 | 용기사 | 8 | 비행. 활에 약함 |
| 세린 | 마법사 | 4 | 사거리 1–2 마법 |
| 미라 | 힐러 | 5 | 옆칸 치료 |

맞으면 사거리 안일 때 반격한다. 회복은 요새/성에서만.
