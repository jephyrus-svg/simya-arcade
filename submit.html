만든 게임을 올리기

HTML 게임을 제출하면 관리자가 확인합니다. 승인이 떨어지면 GitHub Pages에 바로 게시되어 누구나 플레이할 수 있습니다.

1. 제출

제목과 파일을 넣고 GitHub 이슈로 보냅니다. zip은 이 페이지가 만들어 줍니다.

2. 심사

관리자가 플레이해 보고, 문제 없으면 승인 라벨을 답니다.

3. 바로 공개

승인 순간 오락실 목록에 게임이 추가되고, 약 1분 뒤 공개 주소에서 플레이됩니다.

index.html 또는 게임 폴더, zip을 놓거나 클릭해서 고르세요
    GitHub 계정이 필요합니다. 제출을 누르면 zip이 내려가고, 이슈 작성 창이 열립니다. zip을 그 이슈에 첨부하면 심사가 시작됩니다.

    PREVIEW

    관리자 페이지는 admin.html 입니다. 승인 라벨을 달면 자동으로 홈피에 올라갑니다.
